# AcademyBugs – Manual Testing Project

## Project Overview

AcademyBugs is a web application used for practicing manual testing and defect identification across different functional modules.

## My Role

**Manual Tester**

* Prepared and executed manual test cases
* Performed Functional, UI/UX, and Exploratory Testing
* Validated application workflows, data, and user interactions
* Identified, documented, and analyzed defects

## Modules Tested

* Find Bugs
* Product Details
* Report Bugs
* Types of Bugs
* Examples of Bugs
* Shopping Cart
* Checkout
* New User
* Returning Customers
* Store Menu
